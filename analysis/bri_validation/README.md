# BRI validation code

This directory contains the code used to validate the deterministic lexical
Bias Risk Indicator (BRI). Judge-output samples are intentionally omitted from
the public package because they include generated trajectory text that needs a
separate provenance and privacy review before release.

BRI is a conservative lexical audit signal, not semantic ground truth. The
paper's primary intervention table uses skeptical-investigation burden, not BRI,
to avoid treating a lexical score as the intervention target.
