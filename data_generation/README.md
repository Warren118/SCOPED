# Controlled-variant generation

The scripts in this directory are optional. They are not required to reproduce
the aggregate results in the companion data release.

- `hiring/` selects anonymized CV seeds from a separately obtained source file
  and creates controlled hiring variants.
- `credit/` selects and transforms separately obtained credit data into
  simulated credit-underwriting variants.

Do not place source datasets or generated raw trajectories in this repository.
Use an untracked local workspace and respect the source dataset's license,
privacy obligations, and access conditions.
